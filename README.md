# KORAX — تطبيق كرة قدم عربي وعالمي

KORAX تطبيق Android لمتابعة كرة القدم فقط: المباريات والنتائج والأخبار والبطولات والأندية والمنتخبات واللاعبين.

**قرار المنتج:** لا يوجد تسجيل دخول، ولا حسابات سحابية، ولا لعبة فانتازيا. المفضلة والتعليقات والحفظ والإعدادات والنسخ الاحتياطية تعمل محليًا على الجهاز.

## المزايا الموجودة

- أخبار كرة القدم العربية والعالمية من خلاصات الناشرين، مع فلترة خادمية تستبعد الأخبار السياسية والرياضات الأخرى، وعرض المصدر والتاريخ والملخص والصورة عند توفرها.
- صفحة خبر داخل التطبيق تعرض البيانات التي يوفرها RSS وتحفظ الملخص محليًا؛ رابط الناشر يفتح المقال الكامل لديه.
- مباريات مباشرة ومجدولة ومنتهية حسب التاريخ، وتفاصيل إضافية عندما تتوفر لدى SportScore.
- مركز للبطولات وجداول ترتيب البطولات التي تمت مزامنتها.
- بحث عن الأندية والمنتخبات واللاعبين والبطولات، وملفات تعرض الحقول المتاحة من قاعدة بيانات المباريات والتفاصيل.
- مفضلة محلية قابلة للنسخ الاحتياطي والاستعادة، مع تحكم في تنبيهات عناصر المتابعة.
- تنبيهات محلية لأحداث المباريات والأخبار، وفحص خلفي عبر Android WorkManager.
- القراءة دون اتصال لملخصات الأخبار المحفوظة، والتعليقات المحلية، وتصدير/استعادة نسخة احتياطية.

## ما لا يتضمنه التطبيق عمدًا

- لا تسجيل دخول بالبريد أو Google.
- لا فانتازيا، ولا سوق لاعبين أو ميزانيات أو نقاط جولات.
- لا مزامنة للمفضلة أو التعليقات بين الأجهزة.
- لا إشعارات FCM فورية من الخادم؛ التنبيهات الحالية محلية وقد يؤخر Android تشغيل مهام الخلفية حسب البطارية والاتصال.

## دقة البيانات وحدود التغطية

المصدر لا يعيد تفاصيل أو تشكيلات أو إحصائيات لكل مباراة. عند فحص قاعدة البيانات في 24 نوفمبر 2026 كان هناك 1,888 سجل مباراة، و66 سجلًا فقط يحوي تفاصيل إضافية، و7 سجلات جداول ترتيب. لذلك قد تكون بعض ملفات الفرق واللاعبين جزئية، وقد لا تتوفر تشكيلات أو أحداث أو صور لكل مباراة. لا يعرض KORAX أرقامًا أو صفقات أو إصابات غير موجودة في المصدر.

توسعت مزامنة التفاصيل لتدور على المباريات من سبعة أيام سابقة إلى أربعة عشر يومًا قادمة، مع إعطاء الأولوية للمباريات الحية والقادمة ثم النتائج الحديثة. هذا يحسن التغطية بمرور دورات المزامنة؛ ولا يجعل كل تفاصيل المباريات متاحة فورًا.

## البنية النشطة

1. تطبيق Android مبني باستخدام Kotlin وJetpack Compose.
2. عنوان API الافتراضي هو Supabase Edge Function: `korax-api`.
3. GitHub Actions يجلب بيانات SportScore ويكتبها في Supabase عبر `korax-sportscore-sync` باستخدام GitHub OIDC.
4. `korax-api` يعيد عقد بيانات موحدًا للتطبيق ويجمع أخبار الناشرين عبر RSS.
5. مفاتيح الخدمة والتوقيع محفوظة في الخادم وإعدادات CI، ولا توضع مفاتيح الخدمة داخل APK.

مجلد Cloudflare Worker بديل منفصل؛ لكنه ليس عنوان API الافتراضي المضمن في التطبيق.

## البناء والاختبارات

- اسم الحزمة: `com.koora.app`
- الإصدار المستهدف في هذا التحديث: `0.6.8`
- `versionCode`: `15`
- يتم التحقق من Worker وواجهات Supabase واختبارات Android وبناء Release والتوقيع عبر GitHub Actions.
- نجاح CI لا يغني عن تثبيت النسخة واختبار التحديث على هاتف Android فعلي.
