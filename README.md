# KORAX — تطبيق كرة قدم شامل

KORAX تطبيق Android عربي لمتابعة كرة القدم. هذا المستودع يحتوي على التطبيق الحالي وخدمات البيانات والاختبارات. لا يعني وجود ملف أو شاشة أو Edge Function أن الميزة متصلة بالتطبيق أو مكتملة؛ راجع [حالة التنفيذ](docs/IMPLEMENTATION_STATUS.md).

## ما يعمل في النسخة الحالية

- أخبار عربية وعالمية مجمعة من خلاصات الناشرين، مع عرض ملخص وصورة ومصدر وتاريخ عند توفرها.
- صفحة خبر داخل التطبيق، مع الحفظ والمشاركة والتعليقات المحلية ورابط المقال الأصلي.
- مباريات مباشرة ومجدولة ونتائج، مع تفاصيل المباراة عندما يوفر المصدر سجلات تفاصيل فعلية.
- جداول ترتيب البطولات المدعومة حاليًا.
- مفضلة محلية للأندية واللاعبين والبطولات.
- تنبيهات محلية على الجهاز باستخدام WorkManager.

المفضلة والتعليقات والحفظ المحلي لا تتم مزامنتها بين الأجهزة أو المستخدمين. ولا يعرض التطبيق بيانات غير متاحة على أنها بيانات مؤكدة.

## ما لم يكتمل في main

- تسجيل الدخول بالبريد أو Google وحسابات المستخدمين.
- الفانتازي الكامل وأسعار اللاعبين ونقاط الجولات الحقيقية.
- إشعارات FCM الفورية من الخادم.
- مزامنة المفضلة والتعليقات بين الأجهزة.
- قارئ كامل للمقال الأصلي داخل التطبيق؛ المتاح حاليًا ملخص وروابط الناشر.

## المعمارية النشطة

1. تطبيق Android مبني باستخدام Kotlin وJetpack Compose.
2. عنوان API الافتراضي في Gradle هو Supabase Edge Function: `korax-api`.
3. GitHub Actions يشغّل `korax-sportscore-sync.yml` لجلب بيانات SportScore وتخزينها في Supabase باستخدام GitHub OIDC.
4. `korax-api` يقرأ البيانات المخزنة ويعيد واجهة موحدة للتطبيق. خدمة الأخبار تعتمد على خلاصات RSS عامة مع احترام رابط الناشر وعدم إعادة نشر المقال كاملًا.
5. مفاتيح الخدمة والتوقيع تبقى في الخادم/إعدادات CI الآمنة، ولا توضع داخل APK.

## مجلد Cloudflare Worker

المجلد `worker/` يحتوي على محول API مستقل وقابل للنشر عبر `deploy-worker.yml`. لكنه ليس عنوان API الافتراضي المضمن في تطبيق Android الحالي؛ العنوان الافتراضي يشير إلى Supabase. يحتاج نشر Worker إلى GitHub Actions secret باسم `CLOUDFLARE_API_TOKEN`، ولا يحتاجه بناء Android أو مزامنة SportScore إلى Supabase.
